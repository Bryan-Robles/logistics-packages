# Frontend — Logistics Packages

Aplicación web del Módulo 1 (React 19 + TanStack Start + Tailwind + shadcn/ui).

```bash
cp .env.example .env
npm install
npm run dev        # http://localhost:3000
npm run lint
npx tsc --noEmit
```

Requiere el backend en `http://localhost:8080` (ver el [README principal](../README.md)).
